### Added

- **`@capekai/types`**: first publishable release of shared runtime and wire contracts.
- **`@capekai/tool`**: first publishable release of the `ToolModule` authoring contract, including `ToolDefinition`, `ToolResult`, ask-protocol types, and install-manifest literal unions.
- **`@capekai/core`**: first publishable release of the agent framework covering kernel scopes, plugin inventory, execution, hosts, providers, tools, sandbox, the storage contract, neutral defaults, and host layout and guidance seams.

### Changed

- Capek package builds now emit declaration files and JavaScript artifacts with explicit `.js` extensions for Node ESM resolution.
- Public package exports point to built `dist` artifacts rather than workspace source files.
