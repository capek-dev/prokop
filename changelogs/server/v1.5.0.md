### Added

- **Web client included with the server**: every server release now includes the production web client, so installing or updating the server also provides the matching client.
- **Built-in tools**: new installations include tools for reading and editing files, searching projects, running shell commands, asking questions, tracking tasks, fetching web pages, and managing Git worktrees.
- **Clearer tool activity**: tool calls use concise descriptions, completed results stay visible in the conversation, and supported results appear as readable lists or formatted content.
- **Observer mode**: people viewing a session without control now see a read-only conversation with a clear observer status instead of a disabled chat input.
- **Local HTTP access**: the server can provide a plain HTTP address for access from the same machine alongside its secure HTTPS address.
- **Model controls**: the model selector is available in compact session headers, the model picker works better on smaller screens, and GLM-5.3 is available.
- **Server management**: the client automatically connects to the home server, supports renaming saved servers, and has simpler server setup and client-opening flows.
- **Open new chats alongside**: Cmd-click on macOS or Ctrl-click on Windows and Linux opens a new chat beside the current session from either New Chat button.
- **Copy code blocks**: fenced code blocks now include a copy button, including code blocks without a specified language.

### Changed

- **Prokopai naming**: the app, command-line executable, install paths, browser extension, settings, and storage now use Prokop and Prokopai naming. Existing Jean2 settings and data are migrated where needed.
- **Simpler session control**: each session has one controller, and observers can use a direct Take Control action when they need to interact.
- **Smoother conversations**: streaming responses reveal more consistently, conversation scrolling follows only when appropriate, and completed tool results no longer visually jump between states.
- **More stable terminals**: terminal resizing is smoother, restored terminal output appears atomically after reconnecting, and disconnected terminals stay visually still.
- **Consistent tool availability**: bundled, installed, and workspace-provided tools now appear and run through the same tool selection experience.

### Fixed

- **Interrupted sessions**: stopping an assistant run now completes reliably even when an active tool does not respond to cancellation. Sessions incorrectly left running after a shutdown are repaired on startup.
- **Legacy data migration**: moving existing Jean2 data to Prokopai no longer risks opening a new empty database because of stale saved paths.
- **Read-only observer protection**: observers can no longer compact, revert, or fork a session transcript through server requests.
- **Inline tool results**: tool output remains visible after the tool finishes instead of disappearing from the conversation.
- **Client responsiveness**: session and connection updates now avoid several stale display and unnecessary refresh cases.

### Removed

- **Separate web client release**: the web client is no longer distributed separately because it is included in every server release.
- **Electron and VS Code clients**: the desktop Electron app and VS Code extension have been removed. Prokop is now accessed through the web client included with the server.
- **Recommended tool filter**: tools are no longer separated by a recommended status during browsing or installation.
