### Added

- **Agent homes in workspace views**: agent homes can now be selected and used directly from Single workspace and included in Overview groups alongside ordinary workspaces.
- **Unified workspace and agent actions**: the workspace switcher groups ordinary workspaces and agent homes, supports promoting preconfigurations to agents, and provides agent demotion from agent-home actions.

### Changed

- **Simpler agent navigation**: the separate Agents view has been removed. Single workspace and Overview now provide the complete agent-home experience, while existing agent links redirect to the matching workspace route.
- **Clear agent identity**: agent homes use the owning agent's display name and Bot icon across workspace selection, overview sidebars, group configuration, board headers, and multi-session tabs.
- **Mobile workspace switcher**: workspace and agent-home entries scroll within a bounded list on smaller screens while creation and promotion actions remain visible.
- **Agent session defaults**: new chats created in an agent home automatically use the owning agent preconfiguration, with the preconfiguration selector remaining locked to that agent.

### Fixed

- **Agent-home availability**: promotion and demotion now refresh both agent and workspace data immediately, so agent homes appear or disappear without reloading the client.
- **Agent-home labels**: internal agent-home workspace IDs no longer appear in overview and multi-session UI where the agent's display name is available.
