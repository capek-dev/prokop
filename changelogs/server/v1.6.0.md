### Added

- **File explorer rebuild**: the Project tab is now a fast, fully virtualized file tree with file-type icons, built-in search that filters as you type, and your open folders remembered across refreshes and restarts. Clicking a folder just expands it, clicking a file opens it.
- **Changes tab improvements**: the changed-files list is now a proper directory tree (branches open by default) with colored status per file, expand/collapse that persists, and the same search and remembered-state behavior as the Project tab. The old Grouped/Flat toggle is gone since one view now covers both.
- **Reveal open file**: the file you have open in the editor is highlighted and scrolled into view in the explorer.
- **Theme integration**: the explorer follows your app color scheme, including light/dark and all color schemes.
- **Tabs and board layouts**: with multiple sessions open, a tab strip above the panes lets you switch between a tabs view and the side-by-side board (the toggle is disabled when the window is too narrow for the board). Your choice is remembered across reloads. Tabs show a per-session status dot, a badge when a background session is waiting on a permission request, and keep their scroll position and live streaming when you switch between them. Drag the grip on a tab to reorder panes in either layout; up to 6 sessions stay open.

### Fixed

- **Explorer errors**: fixed a crash where opening the file explorer could fail with "Path collides with an existing file" on workspaces containing folders like `.agents`.
- **Keyboard support**: Cmd+2 (files panel) now focuses the file tree so you can navigate with arrow keys immediately; the shortcut also opens the panel if it is closed.
- **Sessions panel border**: a stray vertical line no longer stays visible next to the chat after closing the sessions panel.
- **Tool diff readability**: diff blocks for file edits no longer wrap the file path onto a second line on long paths, and the tiny file icon in the diff header was removed. The same fix applies to created-file blocks, which also keep their path on one line.
- **Board layout after refresh**: on the Overview view, refreshing with several sessions open could leave you with tabs instead of the grid even on a wide screen. Sessions now open side by side again.
- **Board pane overflow**: with all six panes open, opening the sessions panel no longer clipped the rightmost panes; panes always fit inside the available width.
- "ResizeObserver loop" console errors no longer appear when switching tabs on smaller screens or while panels animate.
- **Session actions menu**: the three-dot menu on a session row no longer slides down when you expand or collapse its subagent runs.
- **File preview**: clicking the already-selected file row in the explorer or changes tree re-opens its preview instead of doing nothing.

### Changed

- **Simpler agent navigation**: the separate Agents view has been removed. Single workspace and Overview now provide the complete agent-home experience, while existing agent links redirect to the matching workspace route.
- **Clear agent identity**: agent homes use the owning agent's display name and Bot icon across workspace selection, overview sidebars, group configuration, board headers, and multi-session tabs.
- **Mobile workspace switcher**: workspace and agent-home entries scroll within a bounded list on smaller screens while creation and promotion actions remain visible.
- **Agent session defaults**: new chats created in an agent home automatically use the owning agent preconfiguration, with the preconfiguration selector remaining locked to that agent.
- **Changes tab search**: the header search box is replaced by the tree's built-in search (type while the tree is focused), matching the Project tab exactly. The changed-file count and summed +/− totals moved next to the refresh button in the panel header.

### Fixed

- **Agent-home availability**: promotion and demotion now refresh both agent and workspace data immediately, so agent homes appear or disappear without reloading the client.
- **Agent-home labels**: internal agent-home workspace IDs no longer appear in overview and multi-session UI where the agent's display name is available.
