### Fixed

- **Permission paths in additional workspaces**: shell and terminal approval dialogs now show the path the command will actually modify when it runs from an additional workspace path. Persistent terminals also keep permission paths aligned after changing directories.
- **Mobile chat actions**: message controls such as revert, fork, edit, pin, unpin, and copy are now always visible on phones and tablets instead of requiring a hover state. The subagent session action on tool calls is also visible on touch devices.
