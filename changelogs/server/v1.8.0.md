### Added

- **Terminal starting directories**: new PTY sessions can now start in the primary workspace or a registered additional workspace path instead of always opening in the primary workspace directory.

### Fixed

- **Permission paths in additional workspaces**: shell and terminal approval dialogs now show the path the command will actually modify when it runs from an additional workspace path. Persistent terminals also keep permission paths aligned after changing directories.
- **Mobile chat actions**: message controls such as revert, fork, edit, pin, unpin, and copy are now always visible on phones and tablets instead of requiring a hover state. The subagent session action on tool calls is also visible on touch devices.
- **Long terminal commands**: persistent terminal sends now detect completion markers after verbose output exceeds the response preview limit, so long-running builds and tests do not wait indefinitely for a marker that was already emitted.
- **Directory listing permissions**: the `ls` tool now requests approval before listing directories outside the workspace or sensitive directories, honors approved external paths, and rejects blocked system paths before accessing the filesystem.
