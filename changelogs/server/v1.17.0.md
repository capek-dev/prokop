### Added

- **DeepSeek Flash image capability**: The bundled model configuration now declares image input support alongside text.

### Release note correction

- **Context-selection experiment removed**: The experimental memory and skill selection feature originally announced with this release has been removed. It disrupted provider prompt caching and did not deliver the intended benefit. The TypeSafe Jev integration, expanded memory limits, relevance settings, per-response context details, and selection diagnostics are no longer available. Prokop uses its standard memory assembly behavior.
