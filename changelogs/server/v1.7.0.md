### Added

- **Terminal tool**: a new built-in tool that gives the agent persistent PTY terminal sessions in the workspace. Sessions keep their working directory, environment, and warm build daemons across commands, so repeated compile/test cycles get faster and dev servers keep running while the agent works on something else. Every session the agent creates appears in the terminal panel where you can watch it live or kill it, and sessions die with the workspace. Commands report their real exit code, and a `timeoutMs: null` option waits until long builds actually finish.
- **Explorer context actions**: the file explorer's context menu can now create, rename, and delete files and folders, and copy a path to the clipboard.
- **Opinionated default preconfigs**: fresh installs now ship with a focused set instead of the old generic three: **ProkopCode**, the main coding agent with every built-in tool (including the new terminal tool), investigation-before-analysis and verification discipline in its prompt, delegation to the Explore agent, and self-delegation for parallel implementation work; plus **Explore**, the read-only codebase searcher. Existing installs keep their current preconfigs untouched.

### Changed

- **Question and subagent tools no longer time out**: asking the user a question or running a subagent task used to be killed after five minutes, which could cut off a slow answer or a long exploration mid-flight. Both now wait until they finish and can always be interrupted manually.
- **Tool timeout contract**: tool definitions can now declare `timeout: null` for an explicit "no deadline", which the executor honors instead of substituting a default.
- **Unified code rendering**: the file editor and diff views now share one rendering pipeline (Pierre editor and diff components), so syntax highlighting, line handling, and scrolling behave the same everywhere. Chat code blocks render as proper file blocks.
- **File preview restyle**: the file preview overlay follows the editor toolbar design instead of the old overlay chrome, and the file editor has a single refresh control; diff views refresh with the file reload.
- **Cleaner preconfig tool picker**: capability-gated tools (memory, skills, session search, workflow, scheduler, and their agent variants) no longer appear in the preconfig tools list. They are controlled by the workspace capability toggles, so selecting them in a preconfig never did anything.

### Fixed

- **Diff context**: apply-patch no longer loses the trailing context line when a patch ends at the last line of a file.
- **Preview after workspace switch**: opening a file preview right after switching workspaces no longer fails or shows the wrong workspace's tree, and tree selection follows the opened file correctly.
