### Added

- **Pull requests**: Browse, create, review, and merge GitHub and Azure DevOps pull requests without leaving your workspace. Open Pull requests beside the workspace selector to review changes, leave inline comments, and check review and build status.
- **Azure DevOps sign-in**: Connect to organizations in a different Microsoft tenant from your default Azure sign-in. Missing access now shows the sign-in command you need, and the Azure DevOps CLI extension is no longer required.

### Changed

- **Cleaner settings**: Settings use consistent controls and compact lists. Agent rows show their selected model, and settings that do not apply to Claude Code or Codex are clearly marked.
- **Notification settings**: Sounds and system notifications now have their own Notifications section instead of living under Appearance.

### Fixed

- **Agent settings**: Unsaved edits survive section switches, selecting a new default agent works, and duplicating an agent preserves its memory and skills settings. Reloading agent data now refreshes memory and skills, and tool selection summaries are clearer.
- **Session headers**: Model selectors use the space available in each pane instead of collapsing just because multiple sessions are open.
- **Fewer repeated requests**: Claude and Codex model pickers no longer reload on every session update, and navigating within a server avoids repeatedly fetching workspace and settings data.
- **Claude Code background tasks**: Sessions wait up to 10 minutes for background commands to finish so Claude can report their results. Starting the next message also no longer fails when a previous session left background tasks behind.
- **Windows console windows**: Running Git, Claude, Codex, or opening the browser no longer causes extra console windows to pop up.
