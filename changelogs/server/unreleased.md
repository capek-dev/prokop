### Changed

- Settings panels share one look (`components/modals/configuration/SettingsPrimitives.tsx`). Agents, Prompts, and Formats lists use compact one-line rows like Providers & Models: the description sits inline, agents show their pinned model ("Claude · Sonnet 5" or "Server default"), the row itself opens the editor (the pencil button is gone), and duplicate and delete appear on hover (always visible on touch screens). Errors, empty states, and loading spinners use one shared style across every panel, editors use one header ("New agent", "Edit prompt") instead of repeating the name, and the remaining native `<select>` controls (agent mode, subagents, learning sources, variant and effort, structured output) use the shared Select. Helper text moved from 10px to `text-xs`, and counts are pluralized ("1 skill", "1 subagent"). Sounds and system notifications moved from Appearance to a new Notifications section, Appearance's file open mode uses the same segmented control as theme mode, and Providers & Models has its own icon instead of sharing the MCP one. In the agent editor, Prokop Runtime reads "Not used by Claude CLI" (or Codex CLI) and dims its settings when the agent is pinned to a CLI model, the provider hint shows only for Prokop models, "Home & Memory" is now "Personal files" so it no longer reads like "Memory & Learning", and the model picker no longer uses a monospace font.

### Fixed

- The model selector in a session header now follows the width of its own pane. With more than one session open, every header showed the icon-only selector used on mobile, even when each pane had plenty of room. `ChatHeader` now measures its own width (`hooks/use-element-width.ts`, a `ResizeObserver`): the selector collapses to the icon below 420px, shows only the model name below 640px, and shows the full model, variant, and preconfig label otherwise. Narrow viewports keep their existing mobile and compact forms.
- Agent settings fixes. The Prokop Runtime summary showed "Defaults" when no tools were selected, but the Prokop harness gives such an agent no tools from that list; it now shows "0 tools" and the Tools list says only selected tools are available. The "Reload home data" button refetched the agent list, which never re-ran the memory and skills loader; it now reloads them. Unsaved agent edits were lost on the back arrow or when switching settings sections; the editor draft now lives in the settings dialog (like workspace drafts), so it survives section switches, and the back arrow asks before discarding changed fields. Duplicating an agent now keeps its memory and skills capabilities instead of resetting them to on. Usage now points Codex re-authentication to Providers & Models, and the self-subagent help says "agent" instead of "preconfig". The Default agent switch now works as its help text says ("only one can be the default"): `POST /api/preconfigs` ignored `isDefault` and always created a non-default agent, and `PUT` rejected making an agent default while another one was ("Unset it first"). Both now accept `isDefault` (declared in the route schemas) and move the default to that agent, clearing it on the previous one.
